# Public Library API

## About the Project

The Public Library API is a REST API developed using Node.js and Express.js. It provides an interface for handling library-related requests.

## Technologies Used

* Node.js
* Express.js
* JavaScript

## Installation

1. Clone the repository.

2. Install the dependencies:

   npm install

3. Start the server:

   node server.js

4. Open your browser and visit:

   http://localhost:3000

## Features

* Handles HTTP requests using Express.js.
* Provides API responses in JSON format.
* Demonstrates REST API development using Node.js.
